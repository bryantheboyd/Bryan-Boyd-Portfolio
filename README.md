# Bryan Boyd — Portfolio Site

Production-ready static portfolio built from Bryan Boyd's supplied CV, portrait, reel master, and Endless Coronet assets.

## What is included

- Home
- Work + on-site reel
- Endless Coronet case study + link to the live artwork
- Filterable career Index (42 CV-derived entries)
- About + selected recognition
- Full CV PDF
- Responsive layouts and reduced-motion support
- SEO metadata, sitemap, robots.txt, Cloudflare Pages headers
- Optimized reel derivatives (720p desktop and 540p mobile)
- Authentic supplied/extracted imagery only; no generative portfolio imagery

## Build

This project intentionally has **no runtime or package dependencies**. The pages are generated by a small Node script from structured data.

```bash
npm run build
```

Output goes to `dist/`.

## Preview locally

```bash
npm run preview
```

Then open `http://localhost:4173`.

## Deploy to Vercel

This repository is designed for the existing GitHub → Vercel deployment. Recommended project settings:

- Framework preset: Other
- Root directory: `./`
- Build command: `npm run build`
- Output directory: `dist`

Push changes to the connected `main` branch and Vercel will build and deploy automatically.

## Updating credits

Edit:

`src/data/credits.json`

Then run `npm run build` and redeploy.

Missing years are intentionally not invented because the supplied CV does not provide years for most production credits.

## Updating site facts

Edit:

`src/data/site.json`

## Replacing the CV

Replace:

`public/documents/bryan-boyd-cv-2026.pdf`

If the filename changes, update references in `scripts/build.mjs`.

## Reel

The supplied 4K reel master was not copied into the deploy package. Web derivatives were created instead:

- `public/video/bryan-boyd-reel-web.mp4` — desktop/tablet
- `public/video/bryan-boyd-reel-mobile.mp4` — mobile

The homepage does not request the video until the visitor explicitly opens the reel. The Work page uses `preload="metadata"`.

## Endless Coronet

The portfolio case study is at `/endless-coronet/`.

The artwork itself remains independent at:

`https://www.endlesscoronet.com/`

The portfolio site does not embed or duplicate the artwork backend.

## Design system

The core CSS is:

`src/styles/site.css`

The only client-side behavior is:

`src/scripts/site.js`

This includes:

- gentle reveal motion
- the homepage reel-frame scrub interaction
- reel modal behavior
- Index filtering

No analytics, pixels, cookies, web fonts, third-party JavaScript, CMS, or website-builder runtime are included.
